# Tierwelt der Kanarischen Inseln

Eine Website von **Horst Wilkens** über die Kanarischen Inseln und ihre einzigartige Tierwelt.

## Inhalt

Die Seite stellt die Fauna des vulkanischen Archipels im Atlantik vor:

- **Die Inseln** – wie Isolation und Höhenstaffelung eine außergewöhnliche Artenvielfalt schufen
- **Reptilien** – die endemischen Rieseneidechsen der Gattung *Gallotia*
- **Vögel** – vom namensgebenden Kanarengirlitz bis zum Teneriffa-Blaufink
- **Meerestiere** – Wale und Delfine im Atlantik (Grindwale, Große Tümmler u.&nbsp;a.)
- **Ausgestorbene Riesen** – verlorene Inselgiganten
- **Naturschutz** – verantwortungsvoller Umgang mit dieser Inselwelt

## Technik

Statische Website aus reinem HTML, CSS und JavaScript – keine Build-Schritte nötig.

| Datei | Zweck |
|-------|-------|
| `index.html` | Seitenstruktur und Inhalte |
| `styles.css` | Gestaltung, Layout, responsives Design |
| `script.js` | Mobile-Navigation, Scroll-Animationen, Zähler |

## Lokal ansehen

Einfach `index.html` im Browser öffnen, oder einen lokalen Server starten:

```bash
python3 -m http.server 8000
# dann http://localhost:8000 öffnen
```
